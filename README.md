# CELUNOR — Where Indulgence Meets Wellness

**A premium e-commerce website for chocolates, dry fruits, seeds, and wellness-focused products.**

🔗 **Live Website:** https://celunor.lovable.app/

## About the Project

Celunor is a premium e-commerce web project designed to present food and wellness products through a polished, brand-focused online shopping experience.

The goal was to create a website that combines an elegant visual identity with a structured product catalogue and an administrative interface for managing website content.

I developed this project using **Lovable, an AI-powered development platform**, using carefully designed prompts, iterative refinement, and feedback-driven improvements to shape the website's design and functionality.

## Key Features

- **Premium Brand Experience:** A cohesive visual style designed around the Celunor brand identity.
- **Product Catalogue:** A structured presentation of chocolates, dry fruits, seeds, and wellness-focused products.
- **Admin Dashboard:** An interface for managing products, categories, orders, and website content.
- **Responsive Design:** A modern web interface designed with usability and presentation in mind.
- **Iterative Development:** Website design and functionality refined through prompt-based development and repeated improvements.

## Tools & Technologies

- **Lovable** — AI-assisted website development
- **React** — User interface development
- **TypeScript** — Type-safe JavaScript development
- **Tailwind CSS** — Styling and layout

## My Approach: Prompt Engineering & AI-Assisted Development

Rather than treating AI-generated output as a one-shot result, I used an iterative workflow to guide the development process.

My contribution included:

- Translating the brand concept and website requirements into structured prompts.
- Specifying the desired visual direction, page structure, and user experience.
- Refining generated layouts and components through follow-up prompts.
- Reviewing outputs and adjusting requirements to improve consistency and usability.
- Defining the requirements for an admin dashboard covering key product and content management tasks.

This project helped me explore how **clear requirements, effective prompting, iterative feedback, and product thinking** can be combined to build a functional web experience using AI-assisted development tools.

## What I Learned

- Translating a business concept into a web product.
- Writing structured prompts to communicate design and functionality requirements.
- Iteratively refining AI-generated website output.
- Understanding the relationship between frontend components, styling, and user experience.
- Thinking about both customer-facing interfaces and administrative workflows.
